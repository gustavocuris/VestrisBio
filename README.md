# Vestris Bio

Página responsiva de links, com botões de vidro e ilustração geométrica.

Execute `npm run dev` e abra http://localhost:3000. Requer Node.js; não precisa instalar dependências.

Os botões estão apenas no estágio visual, sem destinos. Os atributos `data-link` identificam cada futuro link.

O fundo e o símbolo em `assets/` são recriações vetoriais das referências. Podem ser substituídos pelos arquivos originais.
